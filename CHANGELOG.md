## [3.0.0] - 2026-04-23

First public release. Adminhtml compatibility module for Magewire 3.0 — adds an authenticated update route, admin component resolver, asset wiring, a prototype pollution fix, and an admin-flavored rate-limiting UI.

Versioned to align with [`magewirephp/magewire`](https://github.com/magewirephp/magewire) 3.0.
